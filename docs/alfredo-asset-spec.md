# 알프레도 상태 머신 — 일러스트 에셋 스펙 v0.1

디자인 시스템 제안(`docs/pwa-design-system.html`)의 "캐릭터가 유일한 장식" 원칙에 따라,
알프레도는 UI에서 허용되는 유일한 일러스트입니다. 이 문서는 상태 머신 정의와
에셋 제작 규격을 명세합니다. `pwa/assets/alfredo/`의 SVG는 단순 도형 기반
**플레이스홀더**이며 정식 일러스트로 교체 대상입니다.

## 1. 상태 머신

근거: Duolingo(사례 25)의 "마스코트 = 상태 표시기" + Finch(사례 26)의 "처벌 없는 친절 루프".
**알프레도는 어떤 상태에서도 화내거나 아프거나 실망하지 않습니다** — 부정 감정 상태는
시스템 차원에서 금지합니다.

| 상태 | 파일 | 트리거 | 무대 대사 톤 |
|---|---|---|---|
| `idle` (대기) | `idle.svg` | 제안 큐 비움 + 보드에 할 일 남음 | "이제 보드에 집중하세요" |
| `investigating` (수사 중) | `investigating.svg` | 분류된 제안이 대기 중 | "밤새 단서 N건을 분류해뒀어요" |
| `curious` (궁금함) | `curious.svg` | 미분류 덤프가 쌓임 / 3일+ 미접속 후 복귀 | "단서가 쌓였어요 — 같이 볼까요?" (죄책감 표현 금지) |
| `celebrating` (사건 종결) | `celebrating.svg` | 오늘 보드 전부 완료 | "사건 전부 종결!" + 스트릭 |
| `offline` (연결 대기) | `offline.svg` | `navigator.onLine === false` | "기록해두고, 연결되면 정리할게요" |

전이 규칙:
- `celebrating`은 하루 1회의 정점 순간 — 도달 시 컨텍스추얼 PWA 설치 유도를 함께 노출 (web.dev 패턴)
- `curious`는 Duolingo식 절박함이 아니라 호기심으로만 표현. 카피에 "안 했네요", "잊으셨나요?" 류 금지
- 상태 전환 애니메이션은 `--motion-emphasis`(320ms spring) 1회만, `prefers-reduced-motion`에서 즉시 전환

## 2. 사용처 매핑 (Headspace 30 — 캐릭터가 시스템 전반의 감정 전달자)

| 서피스 | 상태 | 비고 |
|---|---|---|
| 홈 무대 (stage) | 전체 5종 | 접힘 상태에선 이미지 숨김, 대사만 유지 |
| 빈 상태 (Today 완료) | `celebrating` | 보상형 빈 상태 — 요일별 variant 권장 (Superhuman 19) |
| 오프라인 배너 | `offline` | 32px 축소 사용 |
| 스켈레톤/로딩 | `investigating` | 정적 이미지 + 텍스트, 스피너 금지 |
| 오류 상태 | `curious` | "이상한 단서네요 — 다시 시도해볼까요?" |
| 설치 유도 카드 | `celebrating` | 첫 스트릭/첫 사건 종결 직후에만 |

## 3. 제작 규격

- **포맷**: SVG (마스터), `viewBox="0 0 120 120"` 정사각. 래스터 필요 시 2x PNG 병행
- **팔레트**: 듄 램프 + 기능색만 — 몸통 `#36312B`(dune-800), 배 `#FBFAF6`(dune-0),
  모자 `#1A1510`(dune-950), 부리 `#C97C1E`(fn-should). 임의 색 도입 금지
- **다크 대응**: 위 팔레트는 라이트/다크 지면 양쪽에서 검증됨(몸통이 다크 배경과
  섞이지 않도록 배/눈의 밝은 면적 유지). 테마별 별도 에셋을 만들지 않는 것이 원칙
- **형태 언어**: 곡선 전용, 모서리 없음 (Headspace 블롭 원칙) — 탐정 모자와 돋보기가 유일한 소품
- **네이밍**: `{state}.svg`, variant는 `{state}--{variant}.svg` (예: `celebrating--monday.svg`)
- **접근성**: 모든 사용처에서 인접 텍스트가 의미를 전달하므로 장식적 사용 시 `alt=""`,
  단독 의미 전달 시 상태 설명 alt 필수
