FAQ

Things you might wonder

Is Dumply really free?

Yes, the Chrome extension is free. AI sorting uses your own API key (Claude, OpenAI, or Gemini — BYOK), so there's no subscription.

Do I need an account?

No. Install takes 30 seconds and you can start dumping right away — no sign-up.

Where is my data stored?

Locally in your browser. Your API key is also stored locally and sent only to the AI provider you choose, and calendar data comes straight from the Google API without passing through any external server.

How is this different from a to-do app?

It starts from the premise that not every thought is a task. Feelings are logged as the day's mood instead of becoming tasks, and worries never get forced priorities. Only actionable items surface for today, with MoSCoW priorities.

Can I use it on mobile?

Right now it lives in Chrome's side panel. iOS and Android apps are coming soon.
